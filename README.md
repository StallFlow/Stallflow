# StallFlow

Pre-orders, a till that works without signal, stock and the numbers for
market stalls. Each stall gets its own order page, its own staff app and its
own Google Sheet.

|---|---|---|
| Duxie's Homemade | https://stallflow.github.io/Stallflow/duxies/ | https://stallflow.github.io/Stallflow/duxies/app/ |
